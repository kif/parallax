\begin{synopsis}
Numerical simulation and correction of the 2θ values due to parallax effect, i.e. volumetric absorption of photons in the thickness of the sensor layer.
\end{synopsis}

\begin{abstract}

The parallax effect in X-ray area detectors arises when X-rays from a point source (e.g. a scattering sample) traverse thick detection layers, causing a shift in the apparent position of detected events. This can degrade the angular resolution and introduce artifacts, especially in pair distribution function (PDF) analysis and powder diffraction measurements.
In thick detectors, X-rays at high scattering angles may pass through multiple pixels, leading to discrepancies between observed and actual scattering angles ($2\theta$)

\end{abstract}

\section{Introduction}

Experimental setups are usually calibrated on synchrotron sources using the powder sample  diffraction pattern that is properly characterized (by NIST, typically $\rm LaB_6, CeO_2$, ...).
Those samples show nice concentric Debye-Scherrer rings in their diffraction pattern that are analyzed with tools such as pyFAI-calib2 \cite{pyfai_2020}, Dawn \cite{dawn2027} or GSAS-II \cite{GSAS-II}.
In those tools, assign observed rings to the \textit{d-}spacing of the family of Miller plans and refine the geometry model which is based on Bragg's law:
$$
2d sin({\frac{2\theta}{2}}) = n \lambda
$$

Best calibrations are obtained when using as many rings and as many control points per 
rings as possible.
Nevertheless, the quality of this fit has proven to degrade when including into the 
calibration ring with $2\theta>30$°.
This effect is associated with volumetric absorption of X-ray photons in the sensitive 
layer of the detector, simply refered as parallax effect in the rest of the document.

Parallax effect has three main consquences on the powder diffraction pattern obtaines:
\begin{itemize}
     \item Peak broadening
     \item Peak assymmetry (the peak maximum is usually close to the lowest $2\theta$ values)
     \item Preak profile distortion which are likely to jeoparidize Rietveld refinements
\end{itemize}

Figure 1: Volumetric absorption of photons

In this paper we first describe the various attempts to address the parallax effect, most of them are operating in 1-dimentional space, i.e. after azimuthal integration of the diffraction frame.
Other approaches consist in ensuring photons arrive in the sensitive layer orthogonally, either by using cylindrical, spherical or multiple modules aligned along a circle.

The third chapter presents the physics of volumetric photon absorption which is used to simulate the effect of Beer-Lambert's law with ray-tracing.
This simulation can be stored into a sparse matrix representing the shift and blurring effect of the parallax. Once calculated, this sparse matrix can not only be used to blur a synthetic diffraction image, but also to "deconvolve" an actual image using inverse methods.

In the fourth chapter, we introduce the averaged parallax effect which copes for the displacement of rings. In the fifth chapter, the usage of this correction is discussed with its limitation.

\section{State of the art}
The parallax effect is known for a long time, since this effect is proportionnal to the
sensitive layer thickness and detector were using ionization gaz chambers (several centimeters in size) 
before the avent of CCD detectors coupled with phosphor or scintillators, much thinner.

     \subsection{Ensure the detector is locally orthogonal to the incident beam}

The first attempts to address parallax were by ensuring photons enter the sensitive layer orthogonally.
This can be achieved by manufacturing detectors that are spherical \cite{spherical_detector}, 
planispherical \cite{planispherical} where the sample is located at the center of the sphere.
Another approach is to use a cylindrical detector \cite{cylindrical_detector} where the sample is 
located at the center of the cylinder.
In this configuration, the parallax is accounted for only in one direction, not the other.
Finally this effect can also be mitigated by using several smaller detector assembled in
arrays (Pilatus 12M Diamond), or by rotating a single detector on a $2\theta$ arm.

Those methods suffer all from the same weakness, that the sample needs to be precisely located
at the center of the detector geometry and any deviation may be difficult to account for.

     \subsection{Correct the powder diffraction pattern \textit{aposteriori}}
A simple post-integration data corrections has been proposed to restore the actual 
scattering angle by applying a polynomial correction to the expected scattering angle 
\cite{parallax_polynomial}, possibly coupled with a re-binning of the data to ensure the
$2\theta-$ or q-positions are evenly spaced.
This rebinning creates an extra blurring of the signal. 
The main drawback of the approach is that it requires the detector, supposingly flat, 
to be mounted orthogonally to the incident beam, which is limiting the accessible q-range.

     \subsection{Neural network based corrections}
There is a ParallaxNet \cite{ParallaxNet} autoencoder designed to address the parallax effect
but this autoencoder has been trained to address the variation of the sample - detector distance
duing a diffraction tomography experiment.

That said, the principle could be re-used to take the powder diffraction pattern from a 
database like \textsc{simpod} \cite{simpod} and apply the parallax effect as described 
in section \ref{blur}. 
The ensemble of blurred patterns + theoretical patterns could be used to train a convolutionnal
neural network to perform the unblurring of diffraction images.

\section{Physics of the parallax effect}
     \subsection{Beer-Lambert Law}
The Beer-Lambert law describes the attenuation of light as it passes through matter:
$$ dI = -\mu I dx$$ 
where $\mu$ is the linear attenuation coefficient and $x$ is the path length.
It is more known under its integrated form, showing an exponential attenuation of light intensity:
$$ I = I_0 e^{-\mu x}$$
In X-ray area detectors with thick sensitive layers, this law governs the probability of photon 
interaction at different depths within the detector material.
     \subsection{Simulation of the parallax effect using raytracing}
Raytracing is an old computer vision problem which has been efficiently solved in \citein{raytracing}.
The implementation in pyFAI is a direct re-implementation of this seminal work.
          \subsubsection{Implementation of raytracing in pyFAI}
The software library pyFAI contains a module which performs raytracing, throwing 
several rays per pixel in the detector and measuring for each ray, how long the 
trajectory is in each volumetric pixel (voxel?).

Subsequently, the Beer-Lambert law is applied to descide how much energy is deposited in
each voxel.

All rays thown in a pixel are averaged together and the result is stored in a sparse matrix
where one pixel in the input image contributes to several pixel in the output image.

\begin{verbatim}
     import numpy
     from scipy.sparse import csc_array
     import pyFAI
     from pyFAI.ext.parallax_raytracing import Raytracing

     ai = pyFAI.load("geometry.poni")
     size = numpy.prod(ai.detector.shape)
     rt = pyFAI.ext.parallax_raytracing.Raytracing(ai)

     sparse = csc_array(rt.calc_csr(32),  # throw 32x32=1024 rays per pixel
                        shape=(size, size))
\end{verbatim}

In this example, the \textit{geometry.poni} file contains the detector position and description, 
including the sensor material and thickness. 
It is the typical \textsc{poni}-file produced by the \textit{pyFAI-calib2} application where
all sensor material and thicknesses for all known detectors have been tabulated (~200 detectors).
